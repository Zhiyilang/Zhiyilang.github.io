Excel 两表对账怎么做？用零依赖 Python 脚本替代手工 VLOOKUP

支一郎 · RPA 开发转 AI Agent 工程实战笔记 · 2026-11-05

财务月底对账、运营核对订单与回款，最常见的场景是两张 Excel 表按某个主键（订单号、工号、客户 ID）比对：哪些只在 A 表、哪些只在 B 表、哪些两边都有但金额/状态不一致。本文给你一条零依赖、可重复、可批量的做法，直接替代容易出错的 VLOOKUP 和纯人工核对。

一、手工 VLOOKUP 的三个坑

  • 漏匹：VLOOKUP 默认近似匹配，忘了写 FALSE 就会乱匹配；主键有空格/全半角差异时静默失败。
  • 看不出"仅一边有"：要分别正反查两次才知道哪些是单边数据，容易漏。
  • 量一大就崩：几万行时卡顿、易粘错列，且每次都要重做。

二、零依赖 Python 对账脚本（核心逻辑）

只用 Python 标准库，不装 pandas，跨机器直接跑。思路：把两张表读成字典，主键做集合运算。

import csv

def load(path, key):
    d = {}
    with open(path, encoding="utf-8-sig", newline="") as f:
        for row in csv.DictReader(f):
            d[row[key].strip()] = row
    return d

a = load("表A.csv", "订单号")
b = load("表B.csv", "订单号")
only_a = set(a) - set(b)          # 仅 A 有
only_b = set(b) - set(a)          # 仅 B 有
both   = set(a) & set(b)
mismatch = [k for k in both if a[k]["金额"] != b[k]["金额"]]  # 金额不一致

print("仅A:", len(only_a), "仅B:", len(only_b), "不一致:", len(mismatch))

把 only_a / only_b / mismatch 三份结果各写一个 CSV，就是财务要的"差异清单"。这套逻辑我已封装成零依赖命令行工具，支持多 Sheet、指定主键列、输出三文件，见下方工具。
