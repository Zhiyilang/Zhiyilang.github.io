工资核算 Python 脚本：税前、五险一金与个税累计预扣怎么算

支一郎 · RPA 开发转 AI Agent 工程实战笔记 · 2026-11-05

小团队 HR / 财务每个月算工资，最怕两件事：五险一金基数口径乱、个税累计预扣法算错。Excel 公式一改牵一发动全身。本文给一套零依赖 Python 工资核算脚本思路，附可下载工具与代做入口。

一、工资的四个层次

  • 税前应发 = 基本工资 + 绩效 + 补贴 − 事假扣款
  • 五险一金（个人） = 缴费基数 × 比例（养老 8% / 医疗 2% / 失业 0.5% / 公积金 5%–12%，各地不同）
  • 应纳税所得额 = 累计收入 − 累计免赔（5000×月数）− 累计五险一金 − 累计专项附加扣除
  • 个税（累计预扣） = 应纳税所得额 × 税率 − 速算扣除数 − 已预缴；实发 = 税前应发 − 五险一金 − 个税

二、个税累计预扣核心代码

def cum_pit(taxable, prev_tax=0.0, prev_paid=0.0):
    # 税率表（累计预扣）：不超过36000 → 3%
    brackets = [(36000,0.03,0),(144000,0.10,2520),
                (300000,0.20,16920),(420000,0.25,31920),
                (660000,0.30,52920),(960000,0.35,85920),
                (1e12,0.45,181920)]
    cum = taxable + prev_tax
    rate,k,ded = next((r,k,d) for lim,r,k,d in brackets if cum <= lim)
    due = cum*rate - k - prev_paid        # 本月应补（可为负=不退）
    return max(due, 0.0)

关键点：个税是累计计算，每月要用"累计值"减去"上月已缴"，不是单月独立算。这套逻辑我已封装进 payroll-kit，附 5/5 单元测试，覆盖五险一金与累计预扣。
