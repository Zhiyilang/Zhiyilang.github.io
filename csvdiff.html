csvdiff

按主键对比两个 CSV / JSON，报告新增、删除与字段级变更
\u2190 \u8fd4\u56de\u4e3b\u9875 / \u5168\u90e8\u5de5\u5177 \u00b7 GitHub \u4ed3\u5e93 \u00b7 \u7231\u53d1\u7535\u8d5e\u52a9

两份数据哪里不一样？按主键一行行比对，精确告诉你哪行新增、哪行删除、哪个字段改了值——对账、迁移校验、配置漂移检测都好用。

\u2705 \u529f\u80fd\u7279\u6027

  • 按 --key 主键对齐（支持无表头索引键）
  • 精确报告新增 / 删除 / 字段级变更
  • 支持 --ignore 忽略指定列
  • 输出 JSON / Markdown / HTML
  • 纯标准库，单文件运行

\ud83d\udce5 \u5b89\u88c5\u4e0e\u7528\u6cd5

\u5355\u6587\u4ef6\u3001\u96f6\u4f9d\u8d56\uff0c\u4e0b\u8f7d\u5373\u7528\uff1a

python csvdiff.py old.csv new.csv --key id
# 输出：新增 N 行 / 删除 M 行 / 变更 K 处
