🛠️ 零依赖命令行工具

billfusion

合并微信 / 支付宝 CSV 账单，自动分类、去重、生成月度报表。

python billfusion.py wechat.csv alipay.csv

lanshare

同 Wi-Fi 下手机 ⇄ 电脑互传文件，纯 stdlib 起 HTTP 服务，无需任何客户端。

python lanshare.py serve --port 8000

dupescan

用 SHA-256 跨目录查找重复文件，支持模式过滤、JSON / Markdown 输出、安全删除。

python dupescan.py ./photos --pattern "*.jpg"

csvdiff

按主键对比两个 CSV / JSON，精确报告新增、删除与字段级变更，支持 JSON / HTML 输出。

python csvdiff.py old.csv new.csv --key id

md2html

Markdown → 带样式的 HTML，离线、零依赖，支持 GitHub 风格排版与片段模式。

python md2html.py doc.md -o doc.html

dirsize

目录体积分析，找出吃空间的大文件夹与文件，支持阈值过滤与 JSON 输出。

python dirsize.py ./project --min 10M --top 20

🤖 RPA → AI Agent 工具链

rpa2agent

把 RPA 流程 JSON 编译成可运行的 AI Agent 计划（loop/condition 安全求值，可导出独立 .py）。

python rpa2agent.py flow.json

rpaaudit

RPA 流程静态审计：明文密钥、死循环、脆弱选择器、竞态等 6 类反模式检测器。

python rpaaudit.py flow.json --report
